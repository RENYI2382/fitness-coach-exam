## 〇、通用七步法模板（母版）

所有模块都按这七步走，顺序不能乱，每步 1~2 句话，控制在 60~90 秒内讲完。

| 步骤 | 口令框架 | 一句话示例 |
| :-- | :-- | :-- |
| **1. 寒暄定位** | 问好 + 动作名 + 目标肌肉 + 训练目的 | "你好，今天我们训练【卧推】，主要目标肌肉是【胸大肌】，目的是提升上肢推的力量。" |
| **2. 器械设定** | 检查插销/锁扣/重量/座椅位置/安全带 | "请先检查插销是否插紧、重量是否合适、座椅高度是否与关节对齐。" |
| **3. 初始体态** | 摆好身体位置 + 支点 + 核心收紧 | "请仰卧，保持五点支撑（头、肩背、臀、双脚），收腹挺胸。" |
| **4. 运动轨迹** | 动作的起止路径 + 速度节奏 | "向下时杠铃落于胸部中段，向上时推起至手臂伸直。" |
| **5. 呼吸配合** | 发力时呼气 / 还原时吸气 | "发力向上时呼气，下放还原时吸气。" |
| **6. 关节细节** | 避坑扣分点（锁死、耸肩、塌腰、晃动等） | "推起时肘关节微屈，不要完全锁死；肩胛骨保持下沉。" |
| **7. 保护站位** | 保护者位置 + 手/站位 + 应急说明 | "我会站在你头部后方，双手交叉握住横杠进行保护。" |

## 一、抗阻训练模块（重点，权重最高）

### 1.1 通用话术

1. **寒暄定位**："你好，今天进行【抗阻训练-动作名】，主要训练【目标肌群】，提高肌肉力量/围度。"
2. **器械设定**："先调整器械：插销/杠铃片锁紧、重量根据上次训练水平设定、座椅高度使动作起始位关节对齐。"
3. **初始体态**："身体保持中立位：收腹挺胸、肩胛骨下沉后收、核心收紧，双脚踩实地面（或踩踏板）。"
4. **运动轨迹**："【向心收缩】时沿轨迹缓慢发力至【动作顶点】，【离心收缩】时控制下放至【动作底点】，全程匀速、不要借助惯性。"
5. **呼吸配合**："发力阶段呼气，还原阶段吸气，不要憋气（高血压/心脏问题者更要注意）。"
6. **关节细节**："关节不锁死、不超伸；肘/膝与运动方向一致；躯干不代偿晃动；重量不合适随时停止。"
7. **保护站位**："我在你【前/后/侧】方，一手扶器械/护杠、一手做辅助，动作失控时立即接住，你随时可以喊停。"

### 1.2 常见动作七步话术（速记卡）

| 动作 | 目标肌肉 | 器械设定要点 | 轨迹要点 | 呼吸 | 关节避坑 | 保护站位 |
| :-- | :-- | :-- | :-- | :-- | :-- | :-- |
| **杠铃卧推** | 胸大肌 | 杠铃高度、重量、卡扣 | 杠下落至胸部中段，推起至肘微屈 | 推时呼、落时吸 | 肘不锁死、不耸肩、腰不离凳 | 头后方双手交叉握杠 |
| **深蹲** | 股四头肌/臀 | 杠位高低、安全锁架 | 下蹲至大腿与地面平行，起立还原 | 起时呼、蹲时吸 | 膝不内扣、腰背挺直、全脚掌着地 | 侧后方，双手护杠两端 |
| **硬拉** | 竖脊肌/臀腿 | 杠铃贴小腿、握距 | 挺直腰背将杠拉起至站直，缓慢下放 | 起时呼、放时吸 | 不弓腰、不圆背、杠贴腿走 | 侧方观察，必要时扶髋 |
| **坐姿划船** | 背阔肌 | 把手高度、重量 | 拉至腹部，肩胛后缩，缓慢还原 | 拉时呼、放时吸 | 不耸肩、躯干不后仰过多 | 侧后方辅助 |
| **哑铃飞鸟** | 胸大肌 | 哑铃重量、凳角度 | 肘微屈打开至胸廓水平，夹胸合拢 | 合时呼、开时吸 | 肘不锁死、不耸肩 | 站立侧方，接腕 |

## 二、被动伸展模块

> 被动伸展：教练帮助会员完成拉伸，会员放松，教练施加外力。

1. **寒暄定位**："你好，今天做【目标肌肉】的被动伸展，帮你放松【部位】、改善柔韧性。"
2. **器械/环境设定**："请仰卧（坐姿/俯卧）在垫上，先确认关节活动度没有异常、无急性损伤。"
3. **初始体态**："身体放松，双手放于体侧，被拉伸侧肢体自然放平。"
4. **运动轨迹**："我缓慢地将你的【肢体】移动至【方向】，到达拉伸感明显的位置后停留 15~30 秒。"
5. **呼吸配合**："全程缓慢呼吸，拉伸时呼气放松，不要憋气对抗。"
6. **关节细节**："拉伸幅度以你感到'酸胀但不刺痛'为准；如出现刺痛或麻木立即停止；避免暴力弹振。"
7. **保护站位**："我在你【侧方】，一手固定近端关节、一手缓慢施力；你有任何不适随时告诉我。"

### 常见被动伸展速记卡

| 拉伸部位 | 会员体位 | 施力方向 | 停留时间 | 避坑 |
| :-- | :-- | :-- | :-- | :-- |
| 腘绳肌 | 仰卧抬腿 | 向头侧压腿，膝伸直 | 15~30s | 膝不超伸、不弹振 |
| 股四头肌 | 俯卧屈膝 | 脚跟向臀部压 | 15~30s | 骨盆不抬起 |
| 胸大肌 | 仰卧 | 手臂外展后压 | 15~30s | 肩不耸肩 |
| 髂腰肌 | 仰卧抱膝 | 膝向胸部压 | 15~30s | 腰不离垫 |

## 三、主动伸展模块

> 主动伸展：会员自己完成拉伸，教练指导口令、观察与提示，不直接施力。

1. **寒暄定位**："你好，接下来做【目标肌肉】的主动伸展，请跟着我的口令完成。"
2. **环境设定**："请在垫上站好/坐好，检查周围无障碍物，穿适合运动的服装。"
3. **初始体态**："站姿中立位：双脚与肩同宽，收腹挺胸，目视前方。"
4. **运动轨迹**："请将【肢体】缓慢向【方向】移动，到拉伸感明显处保持；我提示'再向前一点'时继续增加幅度。"
5. **呼吸配合**："每次拉伸时缓慢呼气，保持时平稳呼吸，不要憋气。"
6. **关节细节**："身体其他部位保持稳定，不要借力代偿；幅度以酸胀不刺痛为准；两边对称完成。"
7. **保护站位**："我在你【前方/侧方】观察你的动作，及时纠正；如感觉不适随时停止。"

### 常见主动伸展速记卡

| 拉伸部位 | 起始体位 | 动作口令 | 避坑 |
| :-- | :-- | :-- | :-- |
| 颈部 | 坐/站 | 头向侧倾，同侧手轻压 | 不耸肩、不旋转过快 |
| 肩部 | 站立 | 手臂横过胸前，对侧手拉肘 | 躯干不扭转 |
| 腰背 | 坐姿 | 前屈抱膝，低头弓背 | 不弹振 |
| 小腿 | 弓步压 | 后腿蹬直、脚跟踩实 | 脚跟不离地 |

## 四、有氧器械模块

1. **寒暄定位**："你好，今天进行【跑步机/椭圆机/动感单车】的有氧训练，目标心率区间约【120~140 次/分】。"
2. **器械设定**："先检查设备：急停开关位置、安全带/把手、踏板或车座高度（单车：车座与髋同高，把位合适）。"
3. **初始体态**："上器械后身体直立，目视前方，双手轻扶把手（不紧握、不撑体重），核心收紧。"
4. **运动轨迹**："保持自然步频/踏频，步幅均匀，脚跟先着地过渡到前脚掌（单车：膝盖朝向脚尖方向）。"
5. **呼吸配合**："保持节律性呼吸，两步一吸两步一呼，不要憋气，能说话但不能唱歌的强度为宜。"
6. **关节细节**："肘微屈不锁死，膝盖不内扣；如果出现胸闷、头晕、心悸立即减速并按下急停。"
7. **保护站位**："我在器械侧后方观察你的状态和心率，如有异常随时协助停机。"

## 五、保护模块

1. **寒暄定位**："你好，本次训练由我担任保护，主要负责【动作名】的安全监护与辅助发力。"
2. **器械检查**："再次确认杠铃片锁扣、插销、保护架均在有效位置，重量确认无误。"
3. **站位准备**："我会站在【头部/躯干侧后方】，双脚与肩同宽、重心略低，做好接杠准备。"
4. **保护手法**："【杠铃卧推】双手交叉握杠、跟随杠铃移动；【深蹲】双手护杠两端、随下蹲同步下移；【大重量】使用双人保护。"
5. **呼吸提示**："我喊'呼气'时你发力，'吸气'时还原；力竭时我提示'再推一下'，不要强行硬顶。"
6. **关节提示**："注意不锁死、不代偿；动作变形超过【安全阈值】时我立即接手。"
7. **应急说明**："若发生失控，我将第一时间托住杠铃并引导安全回杠（放回保护架），你只需松开即可。"

## 六、背诵与演练建议

1. **每模块做一张A4口诀卡**，只写"七步关键词"（如：定位→检查→体态→轨迹→呼吸→关节→保护）。
2. **每天3遍**：第1遍看卡读，第2遍半脱稿，第3遍完全脱稿；用手机录音回放自查。
3. **抽签盲测**：把5张模块卡放进盒子，随机抽一张，限时1分钟内完整讲完七步。
4. **考官视角自查**：讲完自问三问——"肌肉说对了没有？呼吸说反了没有？保护站位站对没有？"
5. 线下班重点请教：实际器械型号差异、考官偏好表述、重量选择的实际操作。

## 七、评分标准对齐：扣分红线、细节考点与考场操作建议

> 依据《2026 新国职实操考试评分标准（官方评分表·点对点训练依据）》（output\评分标准.md）整理。
> 使用方式：背诵每模块话术前，先对照本节"红线 + 细节"自查，避免低级丢分。

### 7.1 扣分红线（碰线直接 0 分 / 全扣，务必死记）

| 红线 | 后果 | 话术对应动作 |
| :-- | :-- | :-- |
| 抗阻出现危险动作、关键动作错误 | 该项目直接清零 | 深蹲弓背塌腰、卧推杠铃失控、硬拉圆背等，示范/讲解前先自查姿态 |
| 伸展动作做错 / 出现危险动作 | 单项 0 分 | 动作要点背熟，先讲"位置与姿态→安全提示→发力方向"再演示 |
| 非静力性伸展（动态拉伸） | 0 分 | 科目三只做静力性伸展，口令里明确"到达牵拉感后保持 15~30 秒，不要弹振" |
| 动作方向与幅度答错 | 对应分值全扣，不酌情 | 方向（上/下/前/后、屈/伸）与幅度（90°、与肩同高、不过伸）必须一字不差 |
| 安全提示忘记讲解 | 对应分数一分没有 | 每模块第 6 步"关节细节/避坑"和第 7 步"保护站位"不可省略 |
| 保护手法不标准 | 保护 6 分全扣 | 保护站位、手位、应急接管按模块五话术逐项做到位 |

### 7.2 容易悄悄丢分的细节考点

1. **职业形象 6 分要拿满**：着装 2（统一整洁专业）+ 形体 2（姿态良好）+ 气质 2（仪态端庄自信亲和），进考场先看自己三件事：服装、站姿、表情。
2. **姿态不稳定、身体位置出错 → 1 分 1 分慢慢扣**：身体位置、姿态稳定类维度是"逐项扣"，每错一项扣 1 分，最怕小错不断，示范时保持全程稳定、不晃动。
3. **呼吸节奏、动作速度是小分值考点，易被忽略**：速度 1 分 + 呼吸 1 分（抗阻），强度/时间/呼吸各 2 分（伸展），有氧呼吸无单独项但影响讲解熟练。话术里必须带出"发力呼、还原吸"与"匀速 3~5 次"。
4. **讲解熟练度、动作流畅度 → 考官阶梯扣分**：讲解熟练 3 分、动作熟练 3 分（示范各 3 分），按流畅程度阶梯扣，结巴、卡壳、顺序颠倒都会丢分，练到脱稿秒讲。
5. **保护手法单独 6 分，演示必须标准**：即使动作示范满分，保护手法不标准一样全扣，保护站位/手位/接管三条缺一不可。

### 7.3 考场操作建议（点对点训练）

1. **抗阻动作做 3~5 次，不要过快，边做边口述**：动作要点 + 安全注意事项同步讲，"做一次、讲一句"，节奏稳、不抢时间。
2. **主动伸展 + 被动伸展两套流程都要练熟**：动作要点、强度、时间、呼吸缺一不可，逐项报出："位置与姿态→安全提示→发力方向→强度以牵拉感为准→保持 15~30 秒→缓慢呼吸不憋气"。
3. **有氧模块重点背安全事项（6 分）**，器械实操熟练：急停、把手、踏板/车座调节、心率区间、异常反应处理。
4. **对评分表点对点训练**：把本节 7.1/7.2 的每一项做成自查清单，练一遍话术打一遍勾，覆盖全部考点后再进考场。

### 7.4 每日点对点自查清单（示例）

- [ ] 着装/形体/气质三自查（职业形象 6 分）
- [ ] 抗阻：身体位置→姿态稳定→方向幅度→安全提示→速度→呼吸→讲解→动作（逐项过一遍，方向幅度与安全提示重点背）
- [ ] 保护：站位→手位→接管（演示 1 遍，手法必须标准）
- [ ] 伸展：动作要点→强度→时间→呼吸（只做静力性，时长 15~30 秒）
- [ ] 有氧：安全事项 6 分完整背出 + 器械实操 1 遍
- [ ] 全程计时：单模块 60~90 秒讲完，脱稿流畅
