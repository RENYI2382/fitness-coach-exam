# 新国职健身教练备考一体化平台

面向 2026 年健身教练国家职业技能鉴定（新国职）考试的**离线单文件备考平台**，集刷题、模拟考试、实操视频跟练、评分标准、自查清单于一体。双击 `index.html` 即可使用，无需联网、无需安装。

## 功能

| 模块 | 说明 |
|---|---|
| 📝 刷题 | 1259 题（单选 847 / 判断 412），按 7 大知识领域分类，支持顺序练习 / 模拟考试 / 错题攻坚 / 背题模式，错题自动存入本地 localStorage |
| 🎬 实操训练 | 98 个实训动作视频跟练 + 文字要点，覆盖抗阻训练、被动伸展、主动伸展、有氧器械、保护五类 |
| 📊 评分标准 | 四科目分值、扣分红线、细节考点、考场建议 |
| ✅ 自查清单 | 考前每日打卡自查，进度保存于本地 |

## 7 大知识领域

运动解剖学基础（518 题）、运动生理与代谢（258 题）、器械训练技术（199 题）、营养学基础（171 题）、运动计划设计（89 题）、安全与保护（22 题）、教练职业规范（1 题）

## 快速开始

1. 下载本仓库全部文件到本地**同一目录树**（保持 `index.html` 与 `视频素材/` 在同一盘符下）。
2. 使用 Edge / Chrome 双击 `index.html` 打开。
3. 若视频黑屏，请确认 `视频素材` 与 `index.html` 位于同一盘符（浏览器 file:// 安全策略会拦截跨盘符访问）。

## 目录结构

```
├── index.html          # 一体化备考平台（单文件，Vue2 + Tailwind 内联，无 CDN）
├── data/
│   ├── 题库库.json       # 1259 题统一题库（含解析/知识点/教材溯源）
│   ├── 实训动作库.json    # 98 个动作索引（视频/矢量图/要点）
│   └── 教材知识点库.json  # 教材 OCR 知识点库
├── docs/               # 评分标准、动作卡、实操话术手册等备考文档
├── 矢量素材/             # 98 个动作矢量线稿（SVG）
├── 视频素材/             # 98 个实训动作视频（按分类存放）
├── README.md
└── LICENSE
```
